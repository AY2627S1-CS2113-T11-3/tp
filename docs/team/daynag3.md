# Dayna Gan - Project Portfolio Page

## Overview

Bob is a Java command-line application that helps lab technicians manage inventory, lab sessions, material preparation, contacts, equipment loans, broken items, and student requests. My main contributions are loan tracking and history, persistent storage, shared validation, regression testing, and documentation.

### Enhancements implemented

- **Loan tracking and retained history:** Implemented adding, listing, deleting/voiding, returning, and overdue filtering of loans, integrating `Loan` and `LoanManager` with the parser, UI, contacts, and inventory. Added `list-l history` and `list-l returned`, permanent IDs, lifecycle timestamps, and immutable historical records. This lets technicians trace equipment use after closure. The main challenge was preserving active-list indices while retaining history and restoring stock exactly once. Added version-2 storage and in-memory migration of version-1 loans without rewriting files during loading. ([Loan commands](https://github.com/DaynaG3/tp/commit/33921dc), [returns](https://github.com/DaynaG3/tp/commit/7684b95), [overdue](https://github.com/DaynaG3/tp/commit/6f7abad), [history/migration](https://github.com/DaynaG3/tp/commit/660e511))

- **Persistent record storage:** Implemented automatic saving and startup restoration for inventory, sessions/preparations, contacts, requests, loans, and broken-item reports, preventing data loss between runs. Designed snapshot models, strict JSON validation, atomic file replacement, backup recovery, and failed-save retry/exit handling. Integrated merged features while preserving historical dates and saved stock without deducting quantities again; complete snapshots keep loan and inventory changes consistent. ([Implementation](https://github.com/DaynaG3/tp/commit/982bf7a), [integration](https://github.com/DaynaG3/tp/commit/5d7a7c7))

- **Validation and robustness:** Built the initial inventory/scheduling exception framework and parser validation for formats, categories, duplicates, stock, quantities, indices, dates, times, headcounts, and session conflicts. Strengthened loan errors; added inventory, scheduling, preparation, and loan invariants, null guards, unexpected-command failure containment, and clean exit on closed input. These changes protect state and provide consistent feedback. ([Inventory](https://github.com/DaynaG3/tp/commit/781253e), [scheduling](https://github.com/DaynaG3/tp/commit/6b3bc2d), [failure containment](https://github.com/DaynaG3/tp/commit/5fee10c), [clean exit](https://github.com/DaynaG3/tp/commit/db36025))

- **Maintainability and tooling:** Separated loan queries/confirmations from console rendering, snapshotted borrower details independently of mutable contacts, named parser argument indices, and added diagnostic logging. Clarified shared CLI, contact, inventory, scheduling, preparation, and loan API contracts and test helpers. Renamed starter packages/files to Bob, configured the application entry point, standardized `bob.jar` build/runner references, and added RepoSense attribution while preserving teammates' ownership. ([UI separation](https://github.com/DaynaG3/tp/commit/f3ccc8a), [borrower snapshots](https://github.com/DaynaG3/tp/commit/a999fe1), [logging](https://github.com/DaynaG3/tp/commit/5c1c6c8), [build](https://github.com/DaynaG3/tp/commit/420f08e), [attribution](https://github.com/DaynaG3/tp/commit/e52a05d))

- **Testing and verification:** Added unit tests for loans, parser/UI behavior, overdue dates, validation, invariants, logging, storage round trips, recovery, failed saves, migration, IDs, and stock consistency, plus inventory/scheduling boundary and failure cases. Created the `test-ui` skill, exact-output [UI test plan](../../test/ui-test-plan.md), and PowerShell runner with isolated fixtures, restart checks, transcripts, and case selection; maintained baselines and date expectations. Recorded 370 passing unit tests and zero Checkstyle violations on Java 25; loan-history regression passed 86 cases/620 commands in normal and assertions-enabled modes. Added nine User Guide cases/69 commands, bringing the subsequent upstream audit to 95 cases/689 commands. ([Workflow](https://github.com/DaynaG3/tp/commit/4e1fd77), [runner](https://github.com/DaynaG3/tp/commit/448c8bc), [guide audit and validation record](https://github.com/DaynaG3/tp/commit/d312cc2))
